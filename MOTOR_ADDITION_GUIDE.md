# Motor Addition Guide - SEP Monitoring Dashboard

## Overview

The SEP Monitoring Dashboard now includes multiple ways to add motors, making the process easier and more user-friendly. This guide will help you understand the different options and troubleshoot any issues you might encounter.

## 🚀 Quick Add Motor (Recommended)

The **Quick Add Motor** wizard provides a step-by-step guided experience:

1. **Click the "🚀 Quick Add Motor" button** in the dashboard header
2. **Follow the 3-step wizard:**
   - **Step 1:** Enter a descriptive motor name (e.g., "HVAC Unit 1", "Pump 3")
   - **Step 2:** Enter a unique motor ID (e.g., "MOTOR-001", "PUMP-003")
   - **Step 3:** Specify the location (e.g., "Assembly Line A", "Building 3")

### Benefits of the Wizard:
- ✅ Step-by-step guidance
- ✅ Real-time validation
- ✅ Clear error messages
- ✅ Auto-generated motor ID suggestions
- ✅ Mobile-friendly interface

## 🔧 Advanced Add Motor

For users who prefer a traditional form approach:

1. **Click "Advanced Add Motor"** in the dashboard header
2. **Fill in all three fields:**
   - Motor Name (descriptive name)
   - Motor ID (unique identifier)
   - Location (where the motor is installed)
3. **Click "Add Motor"** to submit

## 📋 Motor Addition Requirements

### Motor Name
- **Required:** Yes
- **Minimum length:** 3 characters
- **Examples:** "HVAC Unit 1", "Conveyor Belt A", "Pump Station 3"

### Motor ID
- **Required:** Yes
- **Format:** Letters (any case), numbers, and hyphens only
- **Must be unique** within your company
- **Examples:** "MOTOR-001", "motor-001", "Pump-003", "hvac-001"

### Location
- **Required:** Yes
- **Examples:** "Assembly Line A", "Building 3", "Floor 2"

## ❓ Need Help?

If you're having trouble adding motors, click the **"❓ Need Help?"** button for a comprehensive troubleshooting guide that covers:

- **Connection Issues** - Internet and authentication problems
- **Form Validation Errors** - Input format requirements
- **Database Errors** - Duplicate IDs and permission issues
- **Authentication Issues** - Login and session problems

## 🔍 Common Issues and Solutions

### "Motor ID already exists"
**Solution:** Choose a different motor ID. The system automatically suggests the next available ID.

### "You must be logged in to add motors"
**Solution:** Log out and log back in, or refresh the page.

### "Failed to add motor"
**Solution:** Check your internet connection and try again. If the problem persists, use the troubleshooting guide.

### Form validation errors
**Solution:** Follow the error messages displayed below each field. They provide specific guidance on what needs to be fixed.

## 🎯 Best Practices

1. **Use descriptive names** that clearly identify the motor's purpose
2. **Follow a consistent ID format** (e.g., MOTOR-001, MOTOR-002)
3. **Include specific location details** for easy identification
4. **Use the Quick Add Motor wizard** for the best user experience
5. **Check the troubleshooting guide** if you encounter any issues
